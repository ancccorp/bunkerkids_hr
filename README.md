# 벙커키즈 HR

벙커키즈 사내 인사관리시스템(HRIS). flex.team의 기능 구성을 참고한 MVP입니다.

## 기능

| 메뉴 | 내용 |
| --- | --- |
| 홈 피드 | 내가 결재할 할 일, 최근 공지, 동료 인정(Kudos), 이번 주 캘린더 |
| 공지 | 목록/상세 분할 화면, 카테고리, 리액션, 댓글, 숨김 (작성은 관리자) |
| 구성원 | 조직별 구성원 디렉터리, 프로필 |
| 구성원 관리 (관리자) | 재직상태 필터 테이블, 근속기간 자동 계산, 구성원 추가/수정, CSV 다운로드 |
| 근무 | 주간 근무표 (기본 10–19시, 근무 기록 수정, 휴가 반영, 휴게시간 자동 공제, 주간 합계) |
| 휴가 | 휴가 유형별 현황, 연차 잔여(마이너스 허용), 종일/반차/시간 단위 신청, 취소 |
| 휴가 관리 (관리자·결재권자) | 승인/반려, 구성원별 연차 현황, 입사일 기준 연차 일괄 부여 |
| 워크플로우 | 지출결의서 등 문서 작성, 다단계 결재선, 승인/반려/취소 |

결재라인: 각 조직의 결재권자(`departments.approver_id`)가 기본 결재자이고, 본인이 결재권자면 상위 조직으로 올라갑니다.

## 실행

Node.js 22.13 이상이 필요합니다 (내장 `node:sqlite` 사용, 별도 DB 설치 불필요).

```bash
npm install
npm run dev        # http://localhost:3000
```

첫 요청 시 `data/hr.db`가 생성되고 가상의 데모 데이터가 들어갑니다. 초기화하려면 `npm run db:reset` 후 서버를 재시작하세요.

## 구조

```
src/lib/schema.ts    테이블 정의
src/lib/seed.ts      데모 데이터 (모두 가상 인물)
src/lib/queries.ts   조회 + 근무표/연차 계산
src/lib/dates.ts     날짜·근속·연차(근로기준법 제60조 단순화) 계산
src/lib/auth.ts      현재 사용자 (개발용 쿠키 전환)
src/app/actions.ts   서버 액션 (모든 쓰기 작업)
src/app/**/page.tsx  화면
```

## 운영 전 해야 할 일

- **인증**: 지금은 사이드바 하단에서 구성원을 골라 전환하는 개발용 방식입니다. Google Workspace SSO 등으로 교체해야 합니다.
- **DB**: SQLite 파일 하나라 서버 1대 기준입니다. 배포 환경에 따라 Postgres 등으로 이전을 검토하세요.
- **연차 계산**: 입사일 기준 단순화 버전입니다. 회계연도 기준/1년 미만 월차 정산 등 회사 정책에 맞게 조정이 필요합니다.
- **공휴일**: 근무표에 공휴일이 반영되지 않습니다.
